# McCormick Media design direction

This documents the existing site direction so future edits stay consistent.

- Identity: cinematic media portfolio for photography, video production, and brand management.
- Palette: near-black surfaces, white type, and electric blue as the single accent.
- Typography: Bebas Neue for large display moments because its condensed shape supports a film-poster voice; Inter for body copy because it stays readable in dense project descriptions and forms.
- Composition: editorial sections, full-bleed imagery, and clear project-led calls to action. Avoid generic SaaS patterns and decorative content.
- Mood: focused, direct, and energetic without being noisy.
- Dial: ENERGY 2 / RHYTHM 2 / MOTION 1.

Decision notes:

- Keep the existing particle-network backgrounds, subtle gradients, and desktop custom cursor; these are part of the retained brand expression.
- The project gallery remains the focal point because the site exists to show the work.
- Preserve the current editorial section spacing and full-bleed image treatment; make only targeted layout adjustments when a viewport needs them.
- Keep the existing reveal, hover, and scroll motion unless a future change explicitly asks for a different interaction model.
- The current responsive baseline stacks content below 768px, with a focused landscape tablet pass for 769–1100px widths.
